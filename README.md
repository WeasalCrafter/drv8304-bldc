This repository contains all of the KiCad files to my BLDC motor controller project, it is based on the example schematic from the datasheet.

<br>

<div align="center">
    <img src="img/layout.png" alt="PCB Layout in KiCad 10.0" height="250">
    <img src="img/schematic.png" alt="PCB Schematic in KiCad 10.0" height="250">
</div>

It was tested and was able to spin a 6s motor with the Arduino SimpleFOC Library.

Read more [here](https://loganfick.com/projects/bldc-results/) on my website!
